    <h1>Create an invoice</h1>
    <div class="endpoint-line">
      <span class="method">POST</span>
      <span class="path">/v1/invoices</span>
    </div>
    <p>Creates a new invoice in <code>draft</code> status. The invoice is not sent to the customer until you call <code>POST /v1/invoices/{id}/send</code>. Line item amounts are summed server-side; the <code>total</code> you send is ignored.</p>

    <section id="overview">
      <h2>Overview</h2>
      <p>The request body is JSON. All monetary values are integers in the smallest currency unit (for example, cents for USD). The <code>currency</code> field is an ISO 4217 code and must match the currency of every line item.</p>
      <p>Requests are idempotent when you supply an <code>Idempotency-Key</code> header. Reusing a key with a different body returns <code>409</code>.</p>
    </section>

    <section id="auth">
      <h2>Authentication</h2>
      <p>Send a bearer token in the <code>Authorization</code> header. Tokens are scoped; this endpoint requires the <code>invoices:write</code> scope.</p>
      <pre><code>Authorization: Bearer sk_live_...</code></pre>
    </section>

    <section id="parameters">
      <h2>Parameters</h2>
      <h3>Path and query</h3>
      <p>None. All input is in the request body.</p>

      <h3>Body fields</h3>
      <table>
        <thead>
          <tr>
            <th>Field</th>
            <th>Type</th>
            <th>Required</th>
            <th>Description</th>
          </tr>
        </thead>
        <tbody>
          <tr>
            <td><code>customer_id</code></td>
            <td>string</td>
            <td><span class="req">required</span></td>
            <td>ID of an existing customer. Must belong to the same account.</td>
          </tr>
          <tr>
            <td><code>currency</code></td>
            <td>string</td>
            <td><span class="req">required</span></td>
            <td>ISO 4217 code, three uppercase letters. Must match all line items.</td>
          </tr>
          <tr>
            <td><code>line_items</code></td>
            <td>array</td>
            <td><span class="req">required</span></td>
            <td>One or more line items. Minimum length 1, maximum 250.</td>
          </tr>
          <tr>
            <td><code>line_items[].description</code></td>
            <td>string</td>
            <td><span class="req">required</span></td>
            <td>Shown on the invoice. Maximum 500 characters.</td>
          </tr>
          <tr>
            <td><code>line_items[].quantity</code></td>
            <td>integer</td>
            <td><span class="req">required</span></td>
            <td>Must be greater than 0.</td>
          </tr>
          <tr>
            <td><code>line_items[].unit_amount</code></td>
            <td>integer</td>
            <td><span class="req">required</span></td>
            <td>Price per unit in the smallest currency unit. Must be 0 or greater.</td>
          </tr>
          <tr>
            <td><code>due_date</code></td>
            <td>string</td>
            <td><span class="opt">optional</span></td>
            <td>ISO 8601 date (<code>YYYY-MM-DD</code>). Defaults to 30 days after creation.</td>
          </tr>
          <tr>
            <td><code>memo</code></td>
            <td>string</td>
            <td><span class="opt">optional</span></td>
            <td>Free text shown on the invoice. Maximum 1000 characters.</td>
          </tr>
          <tr>
            <td><code>metadata</code></td>
            <td>object</td>
            <td><span class="opt">optional</span></td>
            <td>Up to 50 key/value pairs. Keys max 40 characters, values max 500.</td>
          </tr>
        </tbody>
      </table>

      <h2>Response example</h2>
      <p>On success the endpoint returns <code>201 Created</code> with the full invoice object. The <code>total</code> is computed from the line items.</p>
      <pre><code>{

  "object": "invoice",
  "status": "draft",
  "customer_id": "cus_9f2a1b",
  "currency": "USD",
  "due_date": "2025-07-15",
  "memo": "Consulting for June",
  "line_items": [
    { "description": "Consulting", "quantity": 10, "unit_amount": 15000, "amount": 150000 },
    { "description": "Travel", "quantity": 1, "unit_amount": 42000, "amount": 42000 }

  "metadata": { "project": "acme-migration" },

    <section id="errors">
      <h2>Error codes</h2>
      <p>Errors return a JSON body with <code>error.type</code>, <code>error.code</code>, and <code>error.message</code>.</p>
      <table>
        <thead>
          <tr>
            <th>Status</th>
            <th>Code</th>
            <th>Cause</th>
          </tr>
        </thead>
        <tbody>
          <tr>
            <td><span class="status s4xx">400</span></td>
            <td><code>invalid_request</code></td>
            <td>Malformed JSON or a missing required field.</td>
          </tr>
          <tr>
            <td><span class="status s4xx">401</span></td>
            <td><code>unauthorized</code></td>
            <td>Missing or invalid bearer token.</td>
          </tr>
          <tr>
            <td><span class="status s4xx">403</span></td>
            <td><code>insufficient_scope</code></td>
            <td>Token lacks the <code>invoices:write</code> scope.</td>
          </tr>
          <tr>
            <td><span class="status s4xx">404</span></td>
            <td><code>customer_not_found</code></td>
            <td><code>customer_id</code> does not exist or belongs to another account.</td>
          </tr>
          <tr>
            <td><span class="status s4xx">409</span></td>
            <td><code>idempotency_conflict</code></td>
            <td>Idempotency key reused with a different request body.</td>
          </tr>
          <tr>
            <td><span class="status s4xx">422</span></td>
            <td><code>validation_failed</code></td>
            <td>A field failed validation, such as a currency mismatch or a non-positive quantity.</td>
          </tr>
          <tr>
            <td><span class="status s4xx">429</span></td>
            <td><code>rate_limited</code></td>
            <td>Too many requests. Retry after the <code>Retry-After</code> header.</td>
          </tr>
          <tr>
            <td><span class="status s5xx">500</span></td>
            <td><code>internal_error</code></td>
            <td>Unexpected server error. Safe to retry with the same idempotency key.</td>
          </tr>
        </tbody>
      </table>
      <div class="note">Retry <code>429</code> and <code>500</code> responses with exponential backoff. Do not retry <code>4xx</code> responses other than <code>429</code>; the request will fail the same way.</div>

    tabs.forEach(function (tab) {

        var group = tab.closest('.tabs');
        group.querySelectorAll('[role="tab"]').forEach(function (t) {
          t.setAttribute('aria-selected', 'false');
        });
        tab.setAttribute('aria-selected', 'true');
        var container = group.parentNode;
        container.querySelectorAll('.tabpanel').forEach(function (p) {
          p.classList.remove('active');
        });
        document.getElementById(tab.getAttribute('aria-controls')).classList.add('active');
      });
    });

    var links = document.querySelectorAll('.sidebar nav a');
    var sections = Array.prototype.map.call(links, function (a) {
      return document.querySelector(a.getAttribute('href'));
    });
    function setActive() {
      var pos = window.scrollY + 80;
      var current = 0;
      sections.forEach(function (sec, i) {
        if (sec && sec.offsetTop <= pos) current = i;
      });
      links.forEach(function (a, i) {
        a.classList.toggle('active', i === current);
      });
    }
    window.addEventListener('scroll', setActive, { passive: true });
    setActive();
  })();
