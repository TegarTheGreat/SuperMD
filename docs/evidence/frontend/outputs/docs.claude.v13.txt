    <section id="overview">
      <h1>Create an invoice</h1>
      <p class="lede">Creates an invoice for an existing customer. With <code>auto_finalize</code> unset, the invoice is a draft you can still edit; with it set, the invoice is numbered and open for payment immediately.</p>

      <div class="stub">
        <div class="stub-line"><span class="method">POST</span><span>/v1/invoices</span></div>
        <dl class="stub-facts">
          <div><dt>Auth</dt><dd>Bearer token, <code>invoices:write</code></dd></div>
          <div><dt>Idempotent</dt><dd>Via <code>Idempotency-Key</code></dd></div>
          <div><dt>Success</dt><dd>201 with the invoice object</dd></div>
        </dl>
      </div>
      <p class="note">Sample specification: hosts, IDs, limits, and amounts on this page are illustrative.</p>

      <p>Amounts are integers in the currency's smallest unit, so <code>4500</code> in <code>usd</code> is $45.00. Totals are computed server-side; do not send them.</p>
    </section>

    <section id="headers">
      <h2>Headers</h2>
      <div class="table-wrap" role="region" aria-label="Headers table" tabindex="0">
        <table>
          <thead><tr><th scope="col">Header</th><th scope="col">Required</th><th scope="col">Description</th></tr></thead>
          <tbody>
            <tr><td><span class="name">Authorization</span></td><td><span class="tag">required</span></td><td><code>Bearer &lt;api_key&gt;</code>. The key needs the <code>invoices:write</code> scope.</td></tr>
            <tr><td><span class="name">Content-Type</span></td><td><span class="tag">required</span></td><td>Must be <code>application/json</code>.</td></tr>
            <tr><td><span class="name">Idempotency-Key</span></td><td><span class="tag opt">recommended</span></td><td>Unique string up to 64 characters. A retry with the same key and body returns the original response instead of creating a second invoice.</td></tr>
          </tbody>
        </table>
      </div>
    </section>

      <div class="table-wrap" role="region" aria-label="Body parameters table" tabindex="0">
        <table>
          <thead><tr><th scope="col">Name</th><th scope="col">Type</th><th scope="col">Required</th><th scope="col">Description</th></tr></thead>
          <tbody>
            <tr><td><span class="name">customer_id</span></td><td class="type">string</td><td><span class="tag">required</span></td><td>ID of the customer being billed.</td></tr>
            <tr><td><span class="name">currency</span></td><td class="type">string</td><td><span class="tag">required</span></td><td>Three-letter ISO 4217 code, lowercase.</td></tr>
            <tr><td><span class="name">line_items</span></td><td class="type">array</td><td><span class="tag">required</span></td><td>1 to 100 items.</td></tr>
            <tr><td><span class="name">line_items[].description</span></td><td class="type">string</td><td><span class="tag">required</span></td><td>Shown on the invoice. Maximum 250 characters.</td></tr>
            <tr><td><span class="name">line_items[].unit_amount</span></td><td class="type">integer</td><td><span class="tag">required</span></td><td>Price per unit in the smallest currency unit.</td></tr>
            <tr><td><span class="name">line_items[].quantity</span></td><td class="type">integer</td><td><span class="tag opt">optional</span></td><td>Units billed. Default <code>1</code>.</td></tr>
            <tr><td><span class="name">tax_rate_id</span></td><td class="type">string</td><td><span class="tag opt">optional</span></td><td>Tax rate applied to every line item. Omit for no tax.</td></tr>
            <tr><td><span class="name">due_date</span></td><td class="type">string</td><td><span class="tag opt">optional</span></td><td><code>YYYY-MM-DD</code>, today or later. Default: 30 days after finalization.</td></tr>
            <tr><td><span class="name">auto_finalize</span></td><td class="type">boolean</td><td><span class="tag opt">optional</span></td><td><code>false</code> (default) creates a <code>draft</code>. <code>true</code> assigns a number and sets status to <code>open</code>.</td></tr>
            <tr><td><span class="name">memo</span></td><td class="type">string</td><td><span class="tag opt">optional</span></td><td>Free text printed on the invoice. Maximum 500 characters.</td></tr>
            <tr><td><span class="name">metadata</span></td><td class="type">object</td><td><span class="tag opt">optional</span></td><td>Up to 20 string key-value pairs. Not shown to the customer.</td></tr>
          </tbody>

  -d '{
    "customer_id": "cus_8Kq2mT",

    <section id="errors">
      <h2>Error codes</h2>
      <p>Errors return a JSON body with <code>error.code</code>, <code>error.message</code>, and, for validation failures, an <code>error.details</code> array naming each bad field.</p>
      <div class="table-wrap" role="region" aria-label="Error codes table" tabindex="0">
        <table>
          <thead><tr><th scope="col">Status</th><th scope="col">Code</th><th scope="col">Cause and fix</th></tr></thead>
          <tbody>
            <tr><td><span class="status">400</span></td><td><code>invalid_json</code></td><td>Body is not parseable JSON, or <code>Content-Type</code> is wrong.</td></tr>
            <tr><td><span class="status">401</span></td><td><code>unauthorized</code></td><td>Missing, malformed, or revoked API key.</td></tr>
            <tr><td><span class="status">403</span></td><td><code>insufficient_scope</code></td><td>The key lacks <code>invoices:write</code>. Issue a key with that scope.</td></tr>
            <tr><td><span class="status">404</span></td><td><code>customer_not_found</code></td><td><code>customer_id</code> or <code>tax_rate_id</code> does not exist in this account.</td></tr>
            <tr><td><span class="status">409</span></td><td><code>idempotency_conflict</code></td><td>The <code>Idempotency-Key</code> was used earlier with a different body. Use a new key.</td></tr>
            <tr><td><span class="status">422</span></td><td><code>validation_failed</code></td><td>A field failed validation, such as an unknown currency or a past <code>due_date</code>. See <code>error.details</code>.</td></tr>
            <tr><td><span class="status">429</span></td><td><code>rate_limited</code></td><td>Too many requests. Wait for the number of seconds in the <code>Retry-After</code> header.</td></tr>
            <tr><td><span class="status">500</span></td><td><code>internal_error</code></td><td>Server fault. Retry with the same <code>Idempotency-Key</code>; it will not create a duplicate.</td></tr>
          </tbody>
        </table>
      </div>
